# My Website (Static)

Files: index.html, about.html, contact.html, css/style.css, js/script.js

## GitHub Pages par deploy
1. github.com par naya repository banao (e.g. `my-website`), Public rakho.
2. Is folder ki saari files repository mein upload karo (index.html root mein hona chahiye).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / `/ (root)` > Save.
4. 1-2 minute baad site yahan live hogi: https://<username>.github.io/my-website/
